## 1. バグ修正

### 1-1. 戻るボタンが見えにくい
**症状**: 記録画面の戻るボタンが `canGoBack=false` のとき空chevronだけ表示され、`true` のときもテキストのみで分かりにくい。

**修正**: 条件付きで pill 型ボタンに変更。

```jsx
{canGoBack && (
  <div onClick={goBack} style={{
    display:"flex", alignItems:"center", gap:2,
    padding:"4px 12px 4px 6px", borderRadius:20,
    background:C.card, border:`1px solid ${C.divider}`,
    cursor:"pointer", userSelect:"none",
    boxShadow:"0 1px 4px rgba(0,0,0,0.06)"
  }}>
    <i className="ti ti-chevron-left" style={{ fontSize:16, color:C.textSec }}/>
    <span style={{ fontSize:13, color:C.textSec, fontWeight:500 }}>戻る</span>
  </div>
)}
```

---

### 1-2. 死球・故意四球・振り逃げ後に記録画面に戻らない
**症状**: InplayScreen の特殊タブで死球/故意四球/振り逃げを選んでもそのままインプレー画面に留まる。

**修正**: `handleInplayResult` に `setScreen("main")` を追加。振り逃げは `handleWildStrike` 内で処理。

```javascript
// handleInplayResult 内
if (result.special === "DB")  { handlePitch("DB");  setScreen("main"); setHistory([]); return; }
if (result.special === "IBB") { handlePitch("IBB"); setScreen("main"); setHistory([]); return; }
if (result.special === "振")  { handlePitch("振");  return; } // handleWildStrike で画面遷移

// handleWildStrike 内（振り逃げ）
if (queue.length === 0) {
  // ...処理...
  setScreen("main"); setHistory([]); // ランナーなし → 即mainへ
} else {
  closeCurrentAtBat("振り逃げ");
  setScreen("runnerAdvance"); setHistory(["main"]); // historyを絶対指定でリセット
}
```

## 2. コードレビュー＆リファクタリング

### A-1: React CDN を production build に切り替え
開発用ビルドは警告・余分なコードを含むため本番用に変更。

```html
<script src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
<script src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>
```

### A-2: `calcStats` を `useMemo` で最適化
打席毎にゲームログ全体を再計算するコストを削減。

```javascript
const statsA = React.useMemo(() => calcStats(battersA, true),  [gameLog, battersA]);
const statsB = React.useMemo(() => calcStats(battersB, false), [gameLog, battersB]);
```

### A-3: `addScore` のネスト setState を排除
React 18 では同一ハンドラ内の最後の setState が勝つため、クロージャ値を直接使用するように変更。

### A-4: `toastTimer` に `useRef` を使用
タイマーの重複実行（トーストが消えない問題）を防止。

```javascript
const toastTimer = useRef(null);
const showToast = (msg) => {
  if (toastTimer.current) clearTimeout(toastTimer.current);
  setToast(msg);
  toastTimer.current = setTimeout(() => setToast(null), 2000);
};
```

### B-1〜B-4: 不要コードの削除
| 項目 | 内容 |
|------|------|
| B-1 | `INPLAY_RESULTS` 配列を削除（`InplayScreen` に置き換え済み） |
| B-2 | トップレベル `makeHalf` 関数を削除（`initHalf` に置き換え済み） |
| B-3 | `makeShadow` 関数を削除（定義のみで未使用） |
| B-4 | `RUNNERS_INIT_CONST` を削除（`RUNNERS_INIT` の重複） |

### B-4 追加: `buildRunnerQueue` から `RUNNER_PLAYERS` 参照を除去
ランナー名はいったん `{label}ランナー` 表記に変更（C-2 で実際の選手名を対応予定）。

```javascript
const buildRunnerQueue = (r) => {
  const q = [];
  if (r.first)  q.push({ base:"first",  label:"1塁", baseNum:1 });
  if (r.second) q.push({ base:"second", label:"2塁", baseNum:2 });
  if (r.third)  q.push({ base:"third",  label:"3塁", baseNum:3 });
  return q;
};
```

### C-1: ダークモード設定を削除
未実装の `darkMode` state と設定UIを削除し、バージョン表示のみのシンプルな設定画面に。

### Playwright ハマりポイント（学習事項）

| 問題 | 原因 | 解決 |
|------|------|------|
| `div:has-text("xxx")` が親コンテナにマッチ | has-text は最外DOM要素にもマッチする | `div:text-is("xxx")` で完全一致に変更 |
| `[style*="cursor:pointer"]` が機能しない | ヘッドレスChromiumでReactのインラインスタイルは "cursor: pointer"（スペースあり）になる | `div:text-is()` / `span:text-is()` に統一 |
| `text=1塁` が「1塁ランナー」ヘッダーにマッチ | `text=` は部分一致 | `div:text-is("2塁")` で正確一致 |
| `div:text-is("打席結果を入力")` が見つからない | 実際は `span` 内のテキスト | `span:text-is("打席結果を入力")` に変更 |
| select 選択後すぐに確認ボタンを探すと見つからない | React state 更新が非同期 | `waitForTimeout(400)` 追加 |
